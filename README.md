# Tiisetso Khumalo — Editorial Portfolio

Vue 3 + **JavaScript** + **Tailwind CSS** + Vite. Vue single-file components follow **`<template>`, `<script setup>`, `<style scoped>`** ordering.

## Local setup

```bash
npm install
npm run dev
npm run build
```

## Current milestone

- Light-editorial responsive home, work, about, logbook and contact pages.
- Dynamic magazine-style project case-study routes (`/work/:slug`).
- Placeholder visual slots intentionally await **actual application screenshots** and an approved portrait.
- Content is held in `src/data/projects.js` until the admin-backed CMS is implemented.

## Planned milestones

- FastAPI + Supabase-backed protected admin/CMS and image uploads.
- Visitor analytics with appropriate privacy controls.
- Grounded portfolio chatbot with a secured backend.
- Verified live/demo and GitHub project links, expanded case-study writing and approved imagery.

No API keys, confidential client information or unapproved screenshots should be committed. The existing live portfolio is unaffected by this branch.
