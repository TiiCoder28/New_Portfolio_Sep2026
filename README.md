# Tiisetso Khumalo — Portfolio

Light-editorial portfolio built with **Vue 3, JavaScript and Vite**. Public project case studies first; a protected FastAPI admin/CMS, analytics and grounded chatbot are future milestones.

Run locally with `npm install` and `npm run dev`; build with `npm run build`.

Project imagery is awaiting actual approved screenshots. No production secrets or confidential client data should be committed.
